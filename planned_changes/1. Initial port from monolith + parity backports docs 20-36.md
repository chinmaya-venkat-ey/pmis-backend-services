## Why this exists

The monolith was being decomposed and the project domain was the
largest natural slice. Standing up project-mgmt as a mirror let
ops scale the project surface independently of the auth surface
when needed (currently it's a write-only mirror — the FE still
hits the monolith for everything).

## What's in scope / out of scope

- ✅ Project / milestone / activity / task / subtask CRUD
- ✅ Tree endpoint with M-A-T-S aggregation
- ✅ Vendor + division read mirrors
- ✅ Comments + attachments
- ✅ Dashboard read endpoints
- ❌ Anything user-mgmt-owned (login, RBAC writes, 2FA) — stays in
  user-mgmt
- ❌ Notification dispatch — stays in notification-service
